# 晋京 Jinjing 0.1.1

补丁发行版，重点补齐本地聊天记录并重做安装器外观。

## 新增与改进

- 聊天记录自动保存在本机，可从左侧 HISTORY 切换并继续会话
- 聊天记录通过 Windows `safeStorage` 加密，限制为最多 100 个会话、每个 200 条消息
- 恢复旧会话后，首次续聊会向新 Agent 线程注入受限历史上下文
- 安装器改为现代无边框黑色窗口，中央白色“晋”字
- Windows 11 圆角、黑白细线进度、扁平按钮与安装中关闭保护

## 说明

离线数据库、BGE-M3 模型、Codex、Python 和第三方模型连接方式不变。安装器与主程序仍未使用项目方 Authenticode 证书签名。
